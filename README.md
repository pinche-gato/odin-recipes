# odin-recipes
Odin Project Recipes
Recipes are a unique set of instructions that are able to capture a snapshot of family history, culture, or amazing creativity. 
A window into the mind of a person with the simpliest ingredients and methods to the most complex, it allows us to experience food (or beverage) 
from someone at some point in time from their perspective. Obviously the hope is of the person designing the recipe is that it is delicious and people enjoy it.

This project I will be designing a website with recipes that I most enjoy. I will be using my skills of HTML only. This project will not include skills I have not learned, meaning I will not be using MDN web docs, only skills that I feel are proficient. 
Some of the main skills I know with HTML include the basic container tags including <p>, <a>, <img>, and <br>. I will also be using lists including ordered <ol> and unordered <ul> lists. I also have familiarality with forms <form> and emphasis tags like <strong>  and <em>.
